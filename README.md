# Tokyo 3D — ciudad modular

Proyecto de exploración 3D de Tokio en desarrollo. Cada subsistema (calles, edificios, tráfico, peatones, parques, avatar y cámaras) se mantiene en su propio módulo para que un cambio se aplique a todas sus instancias.

**Base de la primera entrega:** escena generada por procedimientos, con lugares representativos de Tokio. No es una réplica cartográfica exacta.
